# Home Assistant add-ons

Home Assistant のアドオンを置いています。

## 追加のしかた

Home Assistant の **設定 → アプリ → アプリストア → ⋮ → リポジトリ** に、
このリポジトリの URL を足してください。

```
https://github.com/Khronos31/hassio-addons
```

## 中身

| アドオン | 説明 |
|---|---|
| [mirakc](mirakc) | PX-S1UD 向け mirakc（siano-ts / recisdb 同梱） |
| [EPGStation](epgstation) | Mirakurun を使用した録画管理ソフト |
